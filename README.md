## Como usar

**Adicionar um trabalho novo:**

1. Copie o template da categoria de [_templates/](_templates/) para dentro da pasta certa, com o nome no formato `AAAA-MM-nome-do-trabalho/`.
2. Renomeie o arquivo copiado para `README.md` dentro dessa pasta.
3. Preencha os campos. Não precisa preencher tudo de uma vez — registre agora, detalhe depois.
4. Jogue as mídias (prints, capas, stills) em `_assets/AAAA-MM-nome-do-trabalho/`.
5. Adicione uma linha no índice acima.

**Exemplo de estrutura:**

```
projetos/
  2026-03-agente-triagem-editorial/
    README.md
audiovisual/
  2025-11-documentario-feira-do-livro/
    README.md
_assets/
  2025-11-documentario-feira-do-livro/
    still-01.jpg
```

**Convenções:**

- Pastas e arquivos em minúsculas, sem acento, separados por hífen.
- Data no nome da pasta = quando o trabalho **começou**.
- Arquivo pesado (vídeo bruto, RAW, PSD) fica fora daqui. Registre o link ou o caminho do drive no README do trabalho.
