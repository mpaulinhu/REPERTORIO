Código HTML gerado

Como usar o código gerado

  1. Preenche o formulário acima e clica em Gerar card.
  2. Clica em Copiar código.
  3. Abre o arquivo site/portfolio.html (e também site/portfolio-src.html, se quiser manter os dois iguais) num editor de texto.
  4. Procura pela linha que tem <!-- FIM DOS CARDS AUDIOVISUAL --> dentro da seção Audiovisual.
  5. Cola o código gerado logo antes dessa linha.
  6. Salva o arquivo e abre no navegador pra conferir.
